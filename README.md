# 瞳伴 · 青少年视力健康管理项目 — 展示网页

视习夹产品与眼视光护理服务主线，含**偏远山区眼健康扩展方案**。本仓库是参加创新创业比赛的
静态展示网站，内容依据两份源文件整理：

| 源文件 | 用途 |
| --- | --- |
| `瞳伴_商业计划书_含山区眼健康扩展.docx` | 14 章正文：摘要、需求、方案、验证、山区扩展、设备清单、AI 边界、财务测算等 |
| `瞳伴_脉动未来团队_山区扩展版_数据图.pptx` | 22 页参赛演示文稿：背景与需求 → 产品与服务 → 验证与商业模式 → 实施与山区扩展 |

## 网站结构

```
index.html      单页展示主页（项目摘要 → 需求 → 产品与服务 → 合规 → 验证 → 山区扩展 → 设备与 AI → 商业 → 实施 → 参考依据）
slides.html     22 页幻灯片视图（方向键翻页 / 缩略图导航 / F 全屏 / 支持手机滑动）
css/style.css   全站样式（含幻灯片视图样式）
js/main.js      导航、滚动入场动画、图表动画、幻灯片控制
js/deck.js      22 页幻灯片的数据结构
assets/img/     商业计划书自带的 3 张示意图
assets/docs/    商业计划书原件（可下载）
```

纯静态站点：零依赖、零构建，直接用浏览器打开 `index.html` 即可，也可直接托管在
GitHub Pages、任何静态服务器或对象存储上。

## 本地预览

```bash
# 方式一：直接双击 index.html

# 方式二：起一个本地服务器
python -m http.server 8321

```

## 内容口径与免责声明

- 视习夹**尚无样机、性能数据、生产报价或真实试点**；文中的合作、用户数量、收入与成本均为待验证计划或测算。

- 南京医科大学是团队背景，不代表学校或附属机构已正式参与。
- 本仓库为比赛展示材料，不构成医疗建议、投资建议或商业承诺。
